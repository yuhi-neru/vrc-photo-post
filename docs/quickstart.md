# VRC Photo Post — はじめに

このフォルダの`VrcPhotoPost.exe`を起動してください。exeだけを別の場所へ移動せず、フォルダ全体を保管してください。

1. 通常起動ではピクチャフォルダの写真一覧を表示します。左側の「写真フォルダ設定」で保存先を変更できます。
2. 写真をダブルクリックするか、1〜4枚を選び「選択した写真でポストを作成」を押します。
3. 左に写真、右にXのWeb画面が開きます。初回は右側で利用者自身がログインしてください。
4. 空の新規投稿欄には画像のワールド名と`#VRchat`を一度だけ初期入力します。名前が取得できない場合はタグだけです。右側で自由に追記・編集し、アカウントと内容を確認します。
5. 投稿を希望する場合だけ、本人がXの投稿ボタンを押してください。アプリは投稿の確定を行いません。

エクスプローラーの写真ダブルクリックから使う場合は、「既定の写真アプリに設定」を押し、Windowsの設定でVRC Photo Postを選びます。写真の右クリック→「プログラムから開く」からexeを選ぶこともできます。

左側のワールド名・`#VRchat`チップは、クリックで文章の末尾へ追加します。同じ内容は重複追加しません。既存の下書きは自動で変更しません。自動入力を確認できない場合は「投稿文をコピー」を押し、右側に貼り付けてください。コピー後に「コピーしました。投稿欄に貼り付けてください」と表示します。

新しい文章入力は実WebView2のローカル画面で検証済みですが、実Xでの動作は未検証です。Xへの自動添付・文章操作の規約上のリスクに変更はありません。

必要な環境はWindows 10／11 x64とMicrosoft Edge WebView2 Runtimeです。.NETは同梱しています。WebView2 Runtimeがない場合はMicrosoft公式サイトから導入してください：
https://developer.microsoft.com/en-us/microsoft-edge/webview2/

閲覧はPNG／JPEG／BMP／TIFF、自動添付はPNG／JPEG、最大4枚、各5MB以下です。元画像は変更しません。通常のEdgeとは別のブラウザ領域でログイン状態を保持します。

**初期テスト版です。ログイン済みの実際のXでPNGの自動添付とプレビューを確認済みです。投稿自体は開発者側では実施していません。** Xの画面変更で動作しなくなる可能性があります。失敗した場合は一部だけ添付されていないか右側を確認してください。アプリは自動再送しません。

旧版のブラウザ拡張は不要です。Windowsの関連付け登録を解除する場合はPowerShell 7で`scripts/unregister-app.ps1`を実行できます。登録解除は写真やログイン用ブラウザ領域を削除しません。

## Xの規約に関する注意

XはAPI以外のWebサイト自動操作を禁止し、一時ロックや永久凍結の可能性を明記しています。このアプリの画像自動添付にもそのリスクがあります。WebView2の使用や手動での投稿確定は、Xの承認・規約適合を保証しません。実験的な初期テスト版として、リスクを理解して利用を判断してください。

公式ルール：https://help.x.com/ja/rules-and-policies/x-automation
